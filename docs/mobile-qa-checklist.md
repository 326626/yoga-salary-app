# 真实手机端验收清单

用于 Vercel 部署后，在真实手机浏览器中做 MVP 验收。建议至少用一台 iPhone Safari 和一台 Android Chrome 检查。

## 一、基础访问

- [ ] 手机浏览器打开 Vercel 地址。
- [ ] 首页正常显示“瑜伽工资助手”。
- [ ] 底部 Tab 不遮挡主要按钮。
- [ ] 页面可以正常上下滚动。
- [ ] 表单输入框和按钮适合手指点击。
- [ ] PWA 可以添加到主屏幕，如果浏览器支持。

## 二、账号流程

- [ ] 可以注册新账号。
- [ ] 可以登录。
- [ ] 可以退出登录。
- [ ] 未登录时不能保存真实数据，并有温柔提示。
- [ ] 刷新页面后登录状态正常。

## 三、基础资料

- [ ] 添加瑜伽馆 / 工作地点。
- [ ] 编辑瑜伽馆。
- [ ] 添加会员。
- [ ] 编辑会员。
- [ ] 添加课包。
- [ ] 课包单节成交价自动计算。
- [ ] 查看课包剩余课时。

## 四、记课流程

- [ ] 手动记一节团课。
- [ ] 手动记一节私教课。
- [ ] 从课包详情快速记一节私教课。
- [ ] 编辑课程。
- [ ] 删除课程。
- [ ] 私教课缺少课包时有提醒。
- [ ] 课包超课时有提醒。
- [ ] 保存成功后最近课程列表更新。

## 五、业绩流程

- [ ] 记录一笔业绩。
- [ ] 编辑业绩。
- [ ] 删除业绩。
- [ ] 可以标记是否计入提成。
- [ ] 保存成功后最近业绩列表更新。

## 六、工资规则

- [ ] 手动输入工资规则文本。
- [ ] DeepSeek 文本识别工资规则。
- [ ] 可以查看可读规则预览。
- [ ] 可以编辑 JSON。
- [ ] JSON 校验失败时有自然提示。
- [ ] 确认后才启用规则。
- [ ] 可以保存通用规则。
- [ ] 可以保存瑜伽馆专属规则。
- [ ] 图片识别入口在不支持时有温柔提示。

## 七、工资计算

- [ ] 按全部瑜伽馆计算工资。
- [ ] 按指定瑜伽馆计算工资。
- [ ] 可以查看课时费明细。
- [ ] 可以查看业绩提成明细。
- [ ] 私教缺少课包时显示 warning。
- [ ] 未归属数据有提示和整理入口。

## 八、工资历史

- [ ] 保存工资快照。
- [ ] 查看工资历史。
- [ ] 按月份筛选。
- [ ] 按瑜伽馆筛选。
- [ ] 标记已结算。
- [ ] 填写实际到账金额。
- [ ] 查看实际到账和预计工资差额。
- [ ] 删除工资快照。
- [ ] 删除快照不影响原始课程、业绩和课包。

## 九、归属整理

- [ ] 查看未归属课程、业绩、课包数量。
- [ ] 选择目标瑜伽馆。
- [ ] 单选记录。
- [ ] 全选 / 取消全选。
- [ ] 批量归属到瑜伽馆。
- [ ] 整理后工资页按瑜伽馆筛选结果正常。

## 十、异常测试

- [ ] 网络慢时 loading 文案友好。
- [ ] 表单必填项缺失时有明确提示。
- [ ] 金额为负数时被拦截。
- [ ] 课时数为 0 或负数时被拦截。
- [ ] 未登录保存时有登录提示。
- [ ] 页面刷新后数据仍然存在。
- [ ] 删除有关联数据时有确认提示。
- [ ] DeepSeek 识别失败时不白屏，并允许手动调整。
