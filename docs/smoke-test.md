# 最小冒烟测试

用于每次部署后快速确认 MVP 主链路是否可用。建议使用一个测试账号完成。

1. 打开首页。
2. 注册新账号或登录已有测试账号。
3. 添加一个瑜伽馆，例如“测试瑜伽馆”。
4. 添加一个会员，例如“李女士”。
5. 添加一个私教课包，例如“私教 10 节”，成交价 3000，总课时 10。
6. 从课包详情点击“用这个课包记一节课”，记录一节私教课。
7. 添加一条业绩，例如私教包成交 3000，计入提成。
8. 添加工资规则，可以使用示例文本并用 DeepSeek 识别。
9. 确认启用工资规则。
10. 进入工资页，按全部瑜伽馆计算工资。
11. 按刚创建的瑜伽馆计算工资。
12. 保存本月工资快照。
13. 进入工资历史，展开快照。
14. 标记为已结算，填写实际到账金额。
15. 退出登录。
16. 重新登录，确认瑜伽馆、会员、课包、课程、业绩、工资规则和工资历史仍然存在。

通过标准：

- 页面没有 500 / 白屏。
- 保存、更新、删除都有自然反馈。
- 所有真实数据只显示当前账号的数据。
- DeepSeek 失败时不影响手动编辑和确认规则。
